# FE ことばノート

基本情報技術者試験の科目Aに役立つ用語を1語ずつカードで見られる、スマホ用の単語帳です。

## スマホで使う

1. PCで `start-lan-server.bat` をダブルクリックします。
2. 表示された `スマホから: http://...:4173/` のURLを、同じWi-Fiにつながったスマホのブラウザで開きます。
3. 1つ以上のジャンルを選んで「単語帳を開く」を押します。単語帳の対象はVer.9.0以降に追加された448語です。全ジャンルから選ぶ場合は「全選択」、選び直す場合は「解除」を押します。
4. 「単語帳を開く」の左にある「シャッフル」をONにすると、最初から用語をランダムに表示します。カードの表面をタップすると説明が開き、裏面をタップすると次の用語へ進みます。図が役立つ344語には図解も表示し、図を拡大して左右に動かせます。メモ欄の操作では進みません。
5. 分からない用語はカード下のボタンでチェックします。画面下の「チェック済み」から、その用語だけをカードで見返せます。

チェック、操作履歴、自分用の説明メモはスマホのブラウザ内に保存されます。別の端末へ移すときは「記録」から書き出し・読み込みを使ってください。PCのサーバー画面を閉じると、スマホからアプリを開けなくなります。

Web画面からの用語追加・編集は提供しません。用語の追加・変更は data/vocabulary.csv で行い、再読み込みして反映します。2026年10月21日に単語帳を新シラバス対象へ切り替えました。変更前の1,000語CSVは `backups/vocabulary-before-new-syllabus-only-20261021.csv` に保存しています。

「用語を読み込めませんでした」と出る場合は、アプリ一式（`index.html`、`data`、`js`、`css`）を同じフォルダに置いたまま、ページを再読み込みしてください。`index.html` をPCで直接開く場合にも用語を表示できます。

2026年10月15日にIPAの公式シラバスVer.9.2と公開問題を照合し、10月21日に単語帳の対象をVer.9.0以降の追加語448件へ変更しました。現在の根拠一覧はシラバス表記一致446件、公開問題のみで表記一致1件、関連項目の学習補足1件（HTTP/3）です。分類はIPAの中分類・小分類を基準にし、処理の流れには独自の学習グループを追加しています。並び順は公式分類の順、学習グループ、読みの五十音順です。収録を続ける448語のIDは保ち、説明は高校生にも分かる言葉と具体例に書き直しました。

照合資料は2012〜2019年度の旧午前16冊、2023〜2026年度の公開科目A4冊、修了試験の公開問題7冊です。本文・選択肢を照合していますが、表記の一致だけではその語自体を問う出題とは断定しません。CBTの未公開問題は照合できず、OCRの不一致は未出題を意味しません。説明には独自の定義、特徴、具体例、用途、比較点を記述しています。出典と公式資料へのリンクは [sources.html](./sources.html) にまとめています。

## 単語データCSVを見る・編集する

- アプリの「記録」→「単語データを見る」、または [database.html](./database.html) を開くと、用語を検索できます。
- 編集するファイルは [data/vocabulary.csv](./data/vocabulary.csv) **1つだけ**です。Ver.9.0、9.1、9.2で追加された語のみ登録でき、`added_in_version` は空欄にできません。`category_id` と `category` の列でジャンルを区別し、`description` 列には仕組み・特徴・具体例・比較点を記入します。
- `id` はチェックやメモの保存に使う識別子です。既存の行を編集するときは変更しないでください。新しい行では重複しない英数字とハイフンのIDを付けてください。引用URLの列と画面上の個別リンクはありません。
- CSVから用語の行を削除した場合も、ページ再読み込み後に単語帳と検索画面から消えます。削除した行のチェック・メモは表示対象から外れます。
- CSVをUTF-8で保存し、スマホのページを再読み込みすると、起動中のPCサーバーがCSVを読み直してカード裏面と検索画面へ反映します。`index.html` を直接開く場合は、先に [update-vocabulary-data.bat](./update-vocabulary-data.bat) を実行してください。
- 現在の収録根拠と照合した資料・PDFページは [reports/exam-vocabulary-evidence.csv](./reports/exam-vocabulary-evidence.csv) で確認できます。`basis` はシラバス表記一致、公開問題の表記一致、学習補足を区別します。全件の説明の修正前後はローカルの `reports/all-description-review.csv` に保存しています。編集前CSV・初期取得資料は `backups`、取得PDFとOCRは `tmp` に保持し、LAN配信や公開用ファイルには含めません。

## 参照資料と公開用ファイル

- アプリのジャンル画面の末尾、または「記録」から「参照資料・収録方針」を開けます。用語ごとの引用URL列は追加していません。
- `node scripts/export-exam-evidence.js` は現在のCSVの行だけを根拠一覧へ書き出します。追加・改名して未照合の行はその旨を表示し、削除した行を戻す処理はありません。
- `node scripts/prepare-public-site.js` で、公開に必要なファイルだけを `public-site` に用意します。GitHub Pages等へアップロードする場合は、その中身を使ってください。ローカルのバックアップ・取得PDF・旧選定レポートは含まれません。この操作自体はインターネットへ公開しません。
- LANサーバーも同じ公開対象一覧を使い、バックアップや旧レポートへアクセスできないようにしています。既にサーバーが動いている場合は、画面を閉じて `start-lan-server.bat` で起動し直してください。


## 新シラバスの対象語

- 単語帳・検索・データ一覧はVer.9.0以降に追加された448語を対象にしています。
- 変更前の1,000語CSVは `backups/vocabulary-before-new-syllabus-only-20261021.csv` に保存しています。バックアップと取得PDFはLAN配信や公開用ファイルに含めません。
- 説明を書き直す前の448語CSVは `backups/vocabulary-before-plain-language-20261021.csv` に保存しています。


## 用語を検索して復習する

- ジャンル画面の検索欄、または下部の「検索」から全用語を探せます。用語名・読み・英語・説明文が対象です。ひらがな／カタカナや全角／半角の違いを吸収し、空白で区切った複数語はすべて含むものを表示します。用語名の完全一致を優先します。
- 検索結果はジャンルとチェック済みで絞れます。「検索結果で単語帳」から、その結果だけのカードを開けます。
- 下部の「チェック済み」では、用語をキーワードとジャンルで絞り、「チェック済みで復習」から表示対象だけを単語帳にできます。左のシャッフルをONにすると順番をランダムにできます。
- 復習ボタンは画面下部に固定し、対象の件数も表示します。チェックを外した用語は、次に作る復習用の単語帳から外れます。
